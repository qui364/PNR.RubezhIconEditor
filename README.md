# PNR.RubezhIconEditor

Редактор библиотек значков устройств (`*.rlib`) системы «Рубеж».

**Онлайн:** https://qui364.github.io/PNR.RubezhIconEditor/

Файлы обрабатываются только в браузере и никуда не отправляются.

## Запуск без интернета

Скопировать папку `src/` и открыть `src/index.html` в Chrome или Edge. Установка не нужна.
